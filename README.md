# Cinema Palette

Générateur de palettes de couleurs **cinématiques** entièrement dans le navigateur.

Outil léger, responsive, multilingue (français, anglais, tamazight/tifinagh). Toutes les opérations sont locales : aucune image ni donnée n’est envoyée.

## Démo

[Ouvrir la démo](https://salimadour31-boop.github.io/cinema-palette/)

## Fonctionnalités

- Presets inspirés du cinéma (Teal & Orange, Noir, Golden Hour, Sci-Fi, etc.)
- Génération selon des harmonies (analogues, complémentaires, triadique…)
- Extraction de couleurs dominantes depuis une image (client-side)
- Export CSS variables, JSON, PNG
- Copie des codes HEX
- Interface claire, sombre, adaptée mobile
- Support Tifinagh via Google Fonts (Noto Sans Tifinagh, OFL)

## Utilisation

1. Ouvre `index.html` dans un navigateur (ou la démo GitHub Pages).
2. Choisis un preset ou une couleur de base + mode d’harmonie.
3. Clique sur une pastille pour copier le HEX.
4. Exporte selon tes besoins.
5. Change de langue (FR / EN / ⵜⵎⵙ) en haut à droite.
